# Viva Questions and Answers

## Practical 1b

**Write a JavaScript Program to get the user registration data and push to array/local storage with AJAX POST method and data list in new page.**

---

### 1. What is JavaScript?

JavaScript is a scripting language used to make web pages interactive.

---

### 2. What is Local Storage?

Local Storage stores data permanently in the browser.

---

### 3. What is AJAX?

AJAX allows sending and receiving data without reloading the webpage.

---

### 4. What is the full form of AJAX?

Asynchronous JavaScript and XML.

---

### 5. What is jQuery?

jQuery is a JavaScript library that simplifies coding.

---

### 6. Why do we use `preventDefault()`?

It prevents page refresh after form submission.

---

### 7. What is JSON?

JSON is a lightweight format for storing and exchanging data.

---

### 8. What is `JSON.stringify()`?

It converts JavaScript object into JSON string.

---

### 9. What is `JSON.parse()`?

It converts JSON string into JavaScript object.

---

### 10. What is Local Storage syntax?

```javascript
localStorage.setItem("key", value);
```

---

### 11. How to get data from Local Storage?

```javascript
localStorage.getItem("key");
```

---

### 12. What is an array?

Array stores multiple values in a single variable.

---

### 13. What is the use of `push()` method?

`push()` adds new data into array.

---

### 14. What is POST method?

POST method sends data to server.

---

### 15. Difference between GET and POST?

* GET → fetch data
* POST → send data

---

### 16. Why use AJAX POST in this practical?

To send registration data without refreshing page.

---

### 17. What is the use of `$.ajax()`?

It performs AJAX request in jQuery.

---

### 18. What is browser storage?

Browser storage stores data on client side.

---

### 19. Difference between Session Storage and Local Storage?

* Session Storage → temporary
* Local Storage → permanent

---

### 20. What is DOM?

DOM stands for Document Object Model.

---

### 21. How do we access HTML element in jQuery?

```javascript
$("#id")
```

---

### 22. What is event handling?

It handles user actions like click and submit.

---

### 23. Why do we use `document.ready()`?

It runs code after page loads completely.

---

### 24. What is form validation?

Validation checks whether input data is correct or not.

---

### 25. Which method is used to redirect page?

```javascript
window.location.href
```

---

### 26. What is client-side storage?

Storage managed inside browser is called client-side storage.

---

### 27. What are advantages of Local Storage?

* Easy to use
* Stores data permanently
* No database needed

---

### 28. What are advantages of AJAX?

* Faster communication
* No page reload
* Better user experience

---

### 29. What is Bootstrap?

Bootstrap is a CSS framework for responsive design.

---

### 30. Why is this practical important?

It demonstrates form handling, storage, AJAX, and dynamic data display in web development.
