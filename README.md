Important Viva Questions with Answers
1. What is Local Storage?

Local Storage stores data permanently in browser.

2. What is AJAX?

AJAX is used to send and receive data without reloading webpage.

3. What is POST method?

POST method sends data to server.

4. What is JSON?

JSON is a lightweight data format used for data exchange.

5. Why use preventDefault()?

It stops page refresh after form submit.

6. What is jQuery?

jQuery is a JavaScript library that simplifies coding.

7. What is localStorage.setItem()?

It stores data in browser local storage.

8. What is JSON.stringify()?

It converts object into JSON string.

9. What is JSON.parse()?

It converts JSON string into object.

10. Difference between GET and POST?
GET → fetch data
POST → send data
